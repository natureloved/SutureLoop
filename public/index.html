Architecture

Six stages. One closed loop.

Every stage emits a typed artifact the next one consumes. Nothing is edited outside the fence, nothing ships without a trace-level diff.

01

Telemetry Ingestion (neatlogs)

Streams runtime exception spans via neatlogs v1.1.26. Clusters duplicate fatal traces into a single crash signature and extracts root file and line coordinates.

emits CrashSignature#9ac1e4f7
02

Blast Radius Analysis (Entire)

Builds a code graph from the AST with Entire v0.11.4, walks callers and callees of processInvoice(), and fences the minimal set of files the agent may touch.

emits ScopeFence[1 file, 3 callers]
03

Atomic Checkpoint

Snapshots the affected demo scope before a single byte changes. Rollback is hash-verified, time-boxed to 30s, and restores clean state in 225ms.

emits CheckpointId cp_1791730154393
04

Adaptive Patch Synthesis & Vitest

Synthesizes safe null navigation inside the fence. When Attempt 1 fails the reproduction test, it executes an atomic rollback in 225ms and retries with failure context.

emits VerifiedDiff#2 (1 rollback)
05

Comparative Trace Evaluation

Replays the failing request against baseline and patched builds in neatlogs, diffing the spans. Asserts error rate drops 1 → 0 with zero unexpected AST mutations.

emits TraceVerdict: PASS
06

Unit Economics Engine (cfo.ai)

Meters tokens, compute, and MTTR savings ($93.75 per fix at $125/hr) against token spend ($0.0011), proving a 99.99% compute gross margin for CFO governance.

emits CostLedger#INC-8644

The loop stays closed. After promotion, telemetry keeps watching the patched symbol. If the same signature re-appears, the incident re-opens with the previous attempt attached as context.

No speculation.

The agent only edits symbols implicated by the crash signature and Entire's AST code graph. If the evidence is thin, it escalates instead of guessing.

Bounded rollback.

Every attempt runs on top of a hash-verified checkpoint with a retry budget and a TTL. Failure always returns to a clean state in 225ms.

Audited economics.

Each fix ships with a cfo.ai cost ledger, measuring reliability ROI in dollars and seconds (>99% gross margin on compute).
